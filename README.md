# Before Started
- First, please create a .env file in the same foler of SearchAgent.py. And inside the .env file, please add your models' API KEY. e.g. DEEPSEEK_API_KEY=sk-c98b52609b2e4ef092435718f6076e9d
- Second, please run "pip install python-dotenv" in your terminal.
- Third, every model in langchain should install a component. e.g. "pip install langchain-deepseek"
- Here is the langchain's reference: https://docs.langchain.com/oss/python/releases/langchain-v1
